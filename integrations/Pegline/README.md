# Pegline 截图晾绳（可选）
上游：https://github.com/2829632740/Pegline
补丁基准提交：2b99cd12463de5999f0e135d0c120cd5a856da02

本项目提供接入脚本，不捆绑 Pegline 可执行文件。
1. 下载上述基准的上游源码。在其目录依次执行 `git apply <hit-test.patch 的绝对路径>`、`git apply <gravity.patch 的绝对路径>`、`git apply <delete-on-close.patch 的绝对路径>`。已经应用的补丁不必重复应用。
2. 执行 pwsh -NoProfile -File ./build.ps1，生成 build/Pegline.exe。
3. 将 Pegline.exe 的完整路径写入 PrismGlass 安装目录下的 pegline-path.txt（一行纯文本）。
4. 下一次开启美化时会启动 Pegline。退出美化时只关闭本次美化启动的实例，不关闭已由用户独立启动的实例。不增加开机启动项。

Ctrl+Alt+T 显示／收起；鼠标在上沿停留也可展开。剪贴板截图接管由 Pegline 首次提示征求用户选择。
点 × 会把原截图移到回收站并取下卡片，无论截图来自哪个文件夹。误删可以从 Windows 回收站恢复。右键“仅取下（保留文件）”不删除原图；清空晾绳和数量超限时的自动取下也不删除原图。

`delete-on-close.patch` 包含这一行为和隔离数据的删除测试。运行 `pwsh -NoProfile -File integrations/Pegline/Test-Discard.ps1 -SourceRoot <已应用全部补丁的源码目录>`，会创建小型临时图片，验证回收外部截图、保留文件的取下、原文件已不存在等情况；不会读取个人挂图记录。系统拒绝回收时会明确提示保留位置，不以永久删除兜底。

## 重力晾绳

- 按住照片左右拖动，可沿绳自由调整位置；松手后照片和绳子继续摆动，逐渐停稳。
- 重量根据相框的显示面积计算，大照片使绳子下垂更明显。两端固定，拖动改变受力位置和绳形；满载时增加张力，避免下垂过深。
- 向下拉约 70 个逻辑像素后进入文件拖拽，可继续拖到应用或文件夹。取消文件拖拽会保留照片。
- 单击复制、双击打开、长按编辑和右键菜单保持可用。
- 位置保存在 `%APPDATA%\Pegline\positions.tsv`，重启后恢复；图片文件不因沿绳移动而被改写。

`gravity.patch` 在点击修复上增加受力模拟、摆动和位置持久化，也包含物理测试与使用生成图片的 WPF 预览验收工具。运行 `pwsh -NoProfile -File integrations/Pegline/Test-Gravity.ps1 -SourceRoot <应用补丁后的源码目录>` 可重新验证。预览工具隔离所有设置和图片数据，不使用个人截图。

验证：物理稳定性、帧率差异、满载边界、拖动跟手、松手连续性、取消及位置保存通过；实际 Windows 预览窗口已用鼠标验证横向拖动。向应用或文件夹传文件仍走原有拖拽逻辑，本轮未向第三方应用实际发送文件。

hit-test.patch 让点击区使用 WPF 实际坐标变换，覆盖旋转、缩放、下滑和 DPI，避免角落按钮落在穿透区。
补丁已编译，真实悬浮窗的点击验收尚未完成。

补丁同时修复加密截图无法回收时只响提示音、卡片不消失的问题：回收失败仍取下卡片，明确提示保留副本的位置，不执行永久删除；每秒清除源文件已不存在的卡片。已用同目录的可丢弃测试文件复现 Windows 的“无法加密指定的文件”异常。
