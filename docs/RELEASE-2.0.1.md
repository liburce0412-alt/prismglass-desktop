# PrismGlass Desktop 2.0.1

适用于 Windows 10/11 x64。安装器支持原位升级。2.0.0 及更早版本请手动运行安装器完成这一次升级。手动升级期间，Windows 托盘中的伴随服务需要短暂停止，重新开启后，iPad 可以沿用原配对开始投屏。[下载 2.0.1](https://github.com/liburce0412-alt/prismglass-desktop/releases/tag/v2.0.1)

- **自动覆盖更新**。在「设置 → 检查更新」开启，默认关闭。通过官方 GitHub Releases 获取安装器，并检查大小和 SHA-256。投屏与共享控制期间可以限速下载，安装会等到空闲。更新后恢复之前运行的组件。安装失败时尝试恢复原程序与皮肤文件。
- **伴随服务独立进程**。桌面与 iPad 伴随服务分别运行。正常退出或重开桌面时，伴随服务继续运行。托盘和开始菜单可直接打开独立伴随屏管理窗口。
- 现有网络配置、设备配对和共享权限可继续使用。已经结束的投屏需在 iPad 重新开始。

自动更新与失败恢复通过隔离回归，安装包提供 SHA-256 校验文件，采用未签名分发。真实从 2.0.1 自动覆盖到后续公开版本，需在后续版本可用后验证。实体多屏和 iPad 音频、触控的验证范围见项目说明。[投屏说明](COMPANION-SCREEN.md) · [验证概述](VALIDATION.md)
