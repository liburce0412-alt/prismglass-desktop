# PrismGlass Desktop 2.0.0

适用于 Windows 10/11 x64。发布页提供安装器和 SHA-256 校验文件。升级前先退出桌面，并在 Windows 托盘关闭正在运行的 iPad 伴随屏。安装器保留已有布局、应用分类、玻璃样式、照片、配对和设备权限。[下载 2.0.0](https://github.com/liburce0412-alt/prismglass-desktop/releases/tag/v2.0.0)

如果新版皮肤与未登记为 PrismGlass 所有的自定义文件同名，安装器会在复制文件前显示冲突路径，保留原文件并停下升级。

## 启动与桌面

- 真正全屏的玻璃开场随启动阶段推进。已选择的 Rainmeter 小组件与 WebView 并行初始化，Dock、面板及小组件就绪后交接桌面。启动失败会恢复 Windows 任务栏和图标。
- 台前调度支持自动、并排、网格和保留位置，可按显示器避开可见栏位。改进切组中途反向、窗口离开及恢复。桌面重入时接续待恢复的窗口，迟到的旧回调无法覆盖当前恢复记录。
- 优化玻璃的共享帧、局部高光和 Dock 反馈。添加专注沙漏、日光窗、期待日历、潮汐休息、专注星仪和待办盆景。新卡片默认关闭，可分别启用并按显示器摆放。
- 天气模块共享同一份本机快照。请求失败时显示可用旧数据和重试状态。亮度滑块读写选中显示器支持的系统亮度，音量界面显示实际静音状态。

## iPad 伴随屏

- 已开启的伴随服务在 PrismGlass 桌面退出和重入时继续运行。可在 Windows 托盘单独关闭，或从 **开始菜单 → PrismGlass → iPad 伴随屏** 打开管理。
- 更新 MediaMTX 改变文件路径时，伴随屏可以在电脑确认后迁移当前安装已有的单设备投屏规则。确认会显示新旧程序路径，Windows 要求管理员同意。
- 投屏和独立副屏继续使用已授权的设备会话。音频、触控和键盘各有独立权限。FFmpeg、MediaMTX 和虚拟显示驱动需要按使用方式自行准备。[投屏配置](COMPANION-SCREEN.md)

## 验证范围

- 发布安装器来自对应提交的 Windows CI，并提供 SHA-256。安装器采用未签名分发。[项目验证入口](VALIDATION.md)
- 上一个本机候选已通过真实快捷方式启动、退出重入、普通桌面恢复、开启伴随服务时的连接连续性，以及修复旧防火墙规则后的实体 iPad 画面。2.0.0 的 MediaMTX 自动迁移、桌面恢复和权限分支由隔离回归覆盖。
- 2.0.0 仍缺少新的实体双屏热插拔、混合 DPI、端到端输入延迟、完全关闭 VPN 后的天气，以及实体 iPad 在桌面切换时的声音和触控验收。硬件亮度、投屏编码和虚拟屏行为取决于设备与驱动支持。
