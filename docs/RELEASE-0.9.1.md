# PrismGlass Desktop 0.9.1

本版修复桌面启动、壁纸刷新和天气地区显示，并加入默认关闭的开机自启选项，以及经过 iPad Air 2 实测的伴随屏投屏与中文键盘输入。

## 下载与升级

下载 **PrismGlass-Setup-0.9.1-x64.exe**，适用于 Windows 10/11 x64。GitHub 的 Source code 压缩包是开发源码，不是安装器。退出 PrismGlass 后运行安装器，在原安装位置升级，保留应用整理、歌词偏好、个人内容和设备配对。

沿用中文向导和 Windows 自带 PowerShell 5.1；缺少 Rainmeter、WebView2 或 .NET Framework 4.8 时可使用向导提供的官方入口。开机自启、伴随屏共享及投屏不会因升级自动开启。

## 桌面修复

- **设置 → 启动与退出** 新增开机自启，默认关闭，只影响当前 Windows 账户；Windows 禁用启动项时会明确提示。
- 快捷方式、直接打开程序和自启统一走完整启动流程。美化就绪后隐藏桌面图标，退出时恢复；托盘退出也停止对应皮肤。
- 顶部刷新玻璃壁纸显示处理中、完成和失败提示。它重新采样当前静态壁纸，不会更换 Windows 壁纸；同一张图再次刷新可能没有可见变化。
- 天气搜索展示完整所属地区，区分同名居民点；移除写死的地区和与当前坐标不一致的外部天气入口。

## 伴随屏

- 可选局域网投屏支持选择显示器与 720p / 1080p，画面铺满页面，控制面板可收起。
- 原生 iPad 键盘支持中文、表情与固定常用按键；中文选词完成后再发送，成功后才清空输入。
- 屏幕、键盘、触控板、电源分别授权，默认关闭，原有配对不会自动获得新增权限。
- 修复 Safari 14 不支持 `inset` 导致全屏画面缩角、并发初次加载失败，以及连接恢复后残留只读超时提示。写入结果未知的警告仍保留。

**投屏是可选功能，需要额外配置。** FFmpeg、MediaMTX 的官方下载入口、建议安装路径、配置文件位置及检查命令见 [投屏安装与配置](https://github.com/liburce0412-alt/prismglass-desktop/blob/v0.9.1/docs/COMPANION-SCREEN.md)。当前编码路径需要兼容的 NVIDIA NVENC，不提供软件编码或其他 GPU 回退；缺少这些组件不影响基础伴随屏的时钟、音乐、应用等功能。

## 验证与边界

本地行为与语法回归、真实 WebView2 设置界面检查通过。原位更新核对 64 份个人设置与配对文件未改变；本机实测启动隐藏图标、退出恢复、玻璃渲染器接收刷新后的采样，自启保持关闭。

真实 iPad Air 2 / iPadOS 14.2 已确认全屏、原生键盘及中文输入正常。短时采样：720p 约 30.02 fps，主屏 1080p 约 30.03 fps；不代表持续数小时稳定性或端到端延迟。

安装包尚未数字签名。投屏无音频，捕获整块显示器，触控采用相对鼠标手势；不提供单软件隔离。未重启 Windows 验证登录自启，未在干净电脑重演全部依赖安装，也未覆盖其他显卡、所有 iPad 或长期功耗。完整范围见 [验证概述](https://github.com/liburce0412-alt/prismglass-desktop/blob/v0.9.1/docs/VALIDATION.md)。
