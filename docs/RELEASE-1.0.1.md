# PrismGlass Desktop 1.0.1 正式版

发布日期：2026-10-30。Windows 10/11 x64 修复版，下载 [PrismGlass-Setup-1.0.1-x64.exe](https://github.com/liburce0412-alt/prismglass-desktop/releases/download/v1.0.1/PrismGlass-Setup-1.0.1-x64.exe)。

## 桌面操作

- 应用中心打开后不再因为鼠标未及时移入而关闭；最小化设置窗口不会覆盖记忆尺寸。
- 修复 Windows 应用商店应用更新后旧固定入口的图标和窗口匹配；适用于 ChatGPT 等版本化应用包。
- Dock、歌词胶囊与顶部灵动岛共用屏幕中心，左右侧栏顶部对齐；重排 Dock 时保留应用各自的缩放过渡。
- 灵动岛显示实际投屏、触控、连接设备、专注、音乐与天气状态，可展开常用操作并停止远程控制。
- 各页面精简宣传语和重复说明，保留必要权限、错误、状态与操作提示。

## iPad 投屏与输入

- 画面使用可用空间并保留原比例，不拉伸、不裁切，也不改变电脑主屏分辨率。
- 主投屏利用已有留白放操作按钮；独立副屏不再固定预留工具列，面板按需展开。
- 原生键盘打开后，右侧留白充足时放置小输入区；其余情况使用约 55 像素的底部输入条，画面底边贴合输入条，保留草稿与输入焦点。
- 触控在前台连接正常时持续开启，空闲和页内切换不会自动停止；后台、断线、锁屏或撤权仍停止控制。
- 投屏连接检查、等待电脑确认、管理员取消与失败都有明确反馈，重新开始不会继承上次失败结果。

## 升级与验证范围

在原安装目录升级，保留应用整理、个人内容、设置与配对。现有证书和网络配置沿用；需要网络修复时仍由用户确认范围。

修复候选已通过行为回归、136 项伴随屏 WebView2 检查、92 项工作区检查、13 项原生布局检查，以及真实 iPad Air 2 / iPadOS 14.2 的横竖屏画面和原生键盘排布检查。用户确认刷新后用手指首次启动投屏正常。详细结果见 [验证概述](VALIDATION.md) 和 [投屏说明](COMPANION-SCREEN.md)。
