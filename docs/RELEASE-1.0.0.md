# PrismGlass Desktop 1.0.0 正式版

发布日期：2026-10-30。Windows 10/11 x64 正式版（非预发布），下载 [PrismGlass-Setup-1.0.0-x64.exe](https://github.com/liburce0412-alt/prismglass-desktop/releases/tag/v1.0.0)。

## 日常操作

- 应用中心和设置中心默认置顶，标题栏可拖动。设置窗口在本次运行内记住位置；重复点击 Dock 应用中心图标收起窗口，失焦和再次打开互不争抢。
- 所有应用共用有超时的窗口恢复和最小化路径，并检查实际结果。拒绝操作或窗口无响应时明确提示。
- iPad 伴随屏管理直接并入设置中心；连接、二维码、证书导出/导入、设备权限与应用共享范围都在同一页。权限仍需显式保存或批准，草稿在切换设备时保留。
- 移除右侧“桌面文件”组件，不删除桌面内容。左侧常用位置与文件浏览继续保留。
- 隐藏及最小化的设置页面暂停后台工作；被遮挡的桌面组件停止无用轮询并尝试休眠，重新显示立即恢复。Sky / Astro 玻璃效果保持。
- 天气改为共享 JSON 采集，优先使用中国气象局 CMA GRAPES 模式（经 Open-Meteo 分发），不可用时回退综合预报。桌面和伴随屏显示有效温度、真实返回的体感值、更新时间与来源；缺失不填 0℃，更新失败明确标记上次数据，超过两小时停止作为当前天气展示。数据属于模式估计，并非气象站实况。

## 伴随屏

修复竖屏首页音乐与待办重叠，横屏投屏页将设置与触控板并排，让主要操作更容易找到。断线时可直接重连，锁屏与网络故障分别说明；连接面板关闭后焦点返回原入口。

修复安装目录末尾分隔符导致投屏修复工具被误报为未安装的问题。保留现有网络边界，证书、URL ACL、防火墙等改动仍先展示范围并请求确认。

## 升级与检查

退出 PrismGlass 后在原安装目录升级，保留应用整理、个人内容、设置和配对。电脑端、隔离网页与真实 iPad 的验收分别记录，详见 [验证概述](VALIDATION.md)。

本地完整回归、构建及原位安装已通过；启动前 67 份个人设置、配对和天气文件保持一致，正常退出后 84 个桌面图标位置一致。已实际检查已安装窗口拖动、伴随屏统一入口和南昌天气显示。资源快照及其限制见验证概述。
