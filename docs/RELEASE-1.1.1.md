# PrismGlass Desktop 1.1.1 正式版

发布日期：2026-11-08。Windows 10/11 x64，下载 [PrismGlass-Setup-1.1.1-x64.exe](https://github.com/liburce0412-alt/prismglass-desktop/releases/download/v1.1.1/PrismGlass-Setup-1.1.1-x64.exe)。

## 玻璃材质与实时背景

- 新增独立的 **设置 → 玻璃** 编辑器，保留动态、浅色、深色、网格预览及拖动观察；提供经典液态、Glasswork、磨砂等基础材质和更多预设。
- 24 项数值参数可调整折射、色散、边缘、染色、模糊、明暗、反光、阴影和颗粒等效果；支持命名保存、重命名、删除本机风格，并同步桌面与伴随屏。
- 保留 Sky 彩色流光和 Astro 白色跟手流光，调整透明度、轮廓裁切、边缘折射和主体采样稳定性。
- 实时背景仍默认关闭。开启时使用 Windows Graphics Capture，只在本机处理后方窗口及 Lively 动态桌面画面；包括 Lively 网页壁纸及同一安装中的 mpv 视频播放器。
- “更新壁纸玻璃”优先保存当前动态壁纸的一帧，没有动态来源才读取静态壁纸；动态捕获失败会显示失败，不再把旧静态图片当作更新成功。
- 多个玻璃窗口共享同一来源的后台捕获，绘制合并到显示帧；采样目标上限提高到 60 帧/秒，保留有界缓冲、只取最新帧、超时停止及关闭释放。更高刷新会增加功耗，目标上限不等于实测帧率。

## 窗口、Dock 与组件

- 新增可选窗口呼出与收拢动效及台前调度：侧倾预览、连续反向切换、窗口并组和拆分；全屏时隐藏对应屏幕的台前区域，超出高度时可滚动并在悬停边缘自动滚动。
- 顶栏、两侧栏与台前区域可拖动保存位置；**设置 → 外观 → 锁定布局** 可统一锁定布局。修正遮挡收起、菜单拆分生命周期和预览画面尺寸处理。
- 提高原生拖动、Dock 预览和提示的更新频率；保留显示刷新驱动的台前调度和浏览器动画、暂停与减少动态效果设置。
- 增加呼吸光球、数字钟、月相与最多六张照片卡片；照片按原图比例显示，可独立换图、移除和控制显隐。默认不自动开启新组件；新增皮肤会刷新 Rainmeter 目录。
- 天气改用随天气和昼夜变化的天空素材；它是视觉示意，非当地实况摄影。回收站固定在 Dock 最右端，原有固定应用顺序保留。
- 应用中心合并可确认属于同一应用的重复入口，保留不同启动参数、分类及排序；歌词、布局和设置保存继续使用已有数据。

## 伴随屏与维护

- 桌面设置、应用中心及伴随屏主页采用对齐模块布局；伴随屏共享玻璃参数，可见氛围动画默认目标 60 帧，持续慢帧仍降级。
- 纳入视频网络规则描述修复、虚拟屏空闲重试及可选 MttVDD 设备开关；网络、证书、声音与控制权限仍独立授权，安装包不自动安装驱动。
- 原位升级保留用户设置、主题、布局、应用整理、照片、配对及已有权限。安装包不包含个人壁纸、运行缓存或配对数据。

## 检查与限制

发布前运行项目行为与语法检查、干净构建及安装包内容检查。现有功能候选已完成真实 WebView2 多宿主捕获、面板连续反向动画、动态网页和 MP4 壁纸取样、安装后短时响应检查。五宿主共享来源的短测采样率由约 14.5 提升至 22 帧/秒；该测试源约 30 Hz，不能据此宣称持续 60 帧。

- 安装包尚未数字签名；没有覆盖所有应用、混合 DPI 多屏、长期负载和新布局的真实 iPad 验收。
- Windows 10/11 功能可用性取决于系统版本、图形驱动和窗口捕获能力；捕获不可用时保留原有壁纸材质。
- Lively 壁纸库的本机修复不是 PrismGlass 安装器功能。若 Lively 自身显示网页加载错误，应先检查它的源文件及库目录；本次观察到异常加密属性导致原库读取异常，相同文件在普通目录可加载。PrismGlass 不自动迁移第三方壁纸库，也不修改系统加密策略。
- NPU 窗口超分仍限于源码实验，不包含模型和专用运行环境，不用于实时投屏。
