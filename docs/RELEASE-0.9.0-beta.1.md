# PrismGlass Desktop 0.9.0-beta.1

首个公开测试安装版，免费开源，沿用 MIT 许可。源码与安装包均在现有仓库发布；这是供实际使用反馈的测试版，不代表所有电脑和设备均已实测。

## 下载与使用

下载 `PrismGlass-Setup-0.9.0-beta.1-x64.exe`。不要将 GitHub 自动提供的 Source code 压缩包当成安装器。

安装面向 Windows 10/11 x64，检查 Rainmeter、PowerShell 7、WebView2 Evergreen Runtime 和 .NET Framework 4.8。缺少依赖时可在向导打开官方下载页，安装后返回继续；不自动捆绑下载依赖。向导主体目前为英文，程序界面与快捷方式为中文。

安装完成后在开始菜单选择“开启 PrismGlass”；退出从托盘或“退出 PrismGlass”入口操作。安装不自动开启美化、不改登录启动、不启用局域网伴随屏。

安装包未进行代码签名，可能显示未知发布者提示。发布附件包含 SHA-256 校验文件用于检查下载完整性；校验值不等同发布者签名，不要求关闭安全软件。

## 本版内容

- 应用中心：分类、文件夹、离线拼音搜索、Dock 固定与拖动整理。
- 统一设置与分屏布局；不同尺寸、缩放及相对位置按各屏处理。
- 保留原有液态玻璃、Sky/Astro、生态瓶与桌面组件。
- 歌词背景配色、专辑取色、Dock/歌词过渡和应用点击最小化/恢复修复。
- iPad 网页伴随屏：配对与权限、媒体与设置、应用入口、触控/滚轮、Touch Bar、小组件与局部电脑控制；系统配置另行确认。
- 新菱形玻璃图标，统一主程序、托盘、安装快捷方式和伴随屏入口。
- 图形安装器、必要依赖引导、标准卸载登记；安装归属与皮肤清单检查，支持本安装器创建的安装覆盖更新并保留个人数据。

## 检查与限制

发行前运行源码行为/语法检查、安装集成隔离检查、Windows 编译和安装器编译，并从对应源码提交重新生成制品。具体结果记在 [验证概述](VALIDATION.md)；这里不把模拟控制、隔离夹具或编译成功写成真实安装和 iPad 实机验收。

- 没有条件全面测试其他电脑、干净 Windows、全部屏幕/GPU/播放器组合；相关兼容性按实际用户反馈继续完善。
- 当前图形安装器未在独立系统实际完成安装、升级和卸载；隔离检查覆盖文件归属、数据保留及路径处理，不能替代系统实测。
- 旧手工部署与无归属同名皮肤不会自动迁移或覆盖。遇到拒绝时保留旧配置，不要删除个人数据强行安装。
- 卸载默认保留个人设置，也保留伴随屏证书和网络配置记录、配置/修复脚本与说明；不会删除共享 Rainmeter、WebView2 或 PowerShell。
- 天气仍以示例位置初始化；图形安装器暂未提供城市选择。开发者脚本可传入坐标。
- 新版伴随屏在 iPad 主屏幕内的相机扫码、关闭重开免输码、真实触控/滚轮与长时间表现尚待实际使用；没有实际执行电源动作来验收。
- 当前没有常驻自动更新服务。后续下载新版安装器完成更新；从托盘“关于 PrismGlass”查看版本。

本次发布没有替换开发者正在使用的桌面安装，没有为了测试扩大网络规则或公开本机证书/配对数据。
