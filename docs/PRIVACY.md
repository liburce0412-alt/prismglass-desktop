# 本地数据与网络请求

- WebView2 只承载本机组件页面，运行目录在安装位置的 `LiquidDesktop/runtime-data`。
- 笔记、事项、链接、生态瓶、可见性、应用固定配置和运行状态均保存在本机安装目录。不要把运行目录整体提交到 Git。
- Codex 额度通过已安装的官方 CLI 执行只读 `account/rateLimits/read` 请求。认证由 CLI 管理，组件不拷贝或解析登录文件，不发送模型请求；本地缓存仅用于显示最近额度。该接口和 CLI 安装位置可能随官方版本变化。
- 天气皮肤向 Open-Meteo 请求安装时设置的经纬度，网络不可用时数据显示可能过期或缺失。公开服务的使用条件以提供方说明为准。
- 可选网易云音乐桥接会读取音乐窗口标题及本机播放队列，并从音乐服务的封面地址获取图片。只有安装时选择 `-EnableMusicBridge` 才启动；没有选择时音乐桥接不运行。
- Dock 歌词有独立开关，默认关闭；开启显示后通过系统 SMTC 读取当前播放元数据与进度，只写本机 `music-data/session.json`。显示关闭或桌面进程退出后停止媒体读取器。
- 网易云 Windows 3.1.41.205529 未提供 SMTC 时，歌词适配器核对版本与模块大小后，以只读权限每约 400 毫秒读取播放进度和时长两个 8 字节数值，并用本机队列校验歌曲时长。没有内存扫描、代码注入或进程写入；其他版本不尝试这些偏移。临时状态写入 `music-data/netease-session.json`，关闭歌词或退出时停止读取并移除该临时状态。
- 歌词在线匹配另行开启，默认关闭。LRCLIB 接收歌曲标题、歌手、专辑与时长；网易云来源可读取本机播放队列以精确匹配歌曲 ID，再向网易云歌词接口发送该 ID。不读取 Cookie、令牌或登录凭据，不上传整个队列、壁纸或其他窗口数据。在线开关关闭后不发起新歌词请求，并丢弃尚未完成请求的结果。
- 同步歌词保存在本机有数量与大小限制的缓存中（最多 32 首）；设置和状态文件位于安装目录。退出后这些本地文件保留，供后续手动开启使用；删除缓存前先退出美化。服务提供方的歌词权利与使用条件不因本仓库 MIT 许可证改变。
- 运行窗口枚举、本地桌面快捷方式和壁纸采样均供桌面功能使用；这些内容没有遥测上传功能。
- 本仓库的构建会请求 NuGet；打开用户自己保存的链接会交给默认浏览器处理。
