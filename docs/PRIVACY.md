# 本地数据与网络请求

- WebView2 只承载本机组件页面，运行目录在安装位置的 `LiquidDesktop/runtime-data`。
- 笔记、事项、链接、生态瓶、可见性、应用固定配置和运行状态均保存在本机安装目录。不要把运行目录整体提交到 Git。
- 应用中心读取用户/公共桌面、用户/公共开始菜单和 Shell 已安装应用目录；手动添加时仅收录用户所选路径。名称、目标、启动参数、来源、分类、单层文件夹、别名与排除记录保存在 `LiquidDesktop/app-library.json`，不进行全盘搜索或上传。图标通过本机 Shell 提取，拼音索引使用随包分发的离线 Unicode 数据。
- 统一设置保存在 `LiquidDesktop/desktop-settings.json`，继续与原有歌词、侧栏和组件状态文件共用数据。显示器设备标识用于恢复各屏配置；注册的唤起快捷键在退出时释放。诊断可能包含组件位置、暂停原因、应用路径和窗口标题，分享日志前应自行查看。
- 顶栏、两侧栏与台前小窗的位置保存在 `LiquidDesktop/component-positions.json`，仅包含显示器标识和位置。呼吸光球、浮游星光与心情卡片不联网，配色及短句选择保存在本机 `ambient-*.txt` 文件；卡片位置由 Rainmeter 保存。
- “实时窗口背景（实验）”默认关闭，单独保存在统一外观设置。开启后请求 Windows 的“无边框窗口捕获”权限，仅用于本机实时玻璃：使用 Windows Graphics Capture 读取玻璃后方窗口，在本机共享内存中交给 WebGL 做折射。跳过隐藏、最小化及受保护窗口；各宿主共享同一窗口的采集，整个进程至多六个来源、原始画面合计约三千二百万像素；背景取样目标上限 120 帧/秒、传递帧至多约一百万像素，界面动画独立运行。关闭、暂停、锁屏或宿主隐藏时停止并释放采集缓冲区；捕获不可用时使用原有壁纸材质。连续实时捕获不保存或上传背景帧。用户主动点击“更新玻璃壁纸”时，优先将当前 Lively 动态壁纸的一帧写入既有本机壁纸缓存；没有动态来源才取静态壁纸，捕获失败不回退为静态成功。不修改截图排除标志、系统透明度开关或伴随屏权限；用户已开启的截图、录屏和伴随屏共享仍可能包含玻璃中可见的内容。
- Dock 窗口动效和台前缩略组会为用户操作的窗口在内存中暂存快照，不采集标记受保护的窗口。无缓存的 Dock 还原直接交给系统；已有快照的还原交接仍会短时隐藏真实窗口，随后恢复原有样式，取消、失败和下次启动都有恢复处理。不注入其他应用，不接管全局最小化按钮或修改系统动画设置。
- 台前调度缺少最小化窗口的快照时，使用 Windows DWM 保留的缩略图，经单个屏外临时窗口读取一帧，继续在本机内存中显示。检查来源进程与窗口身份以及捕获保护，不恢复后台应用、不抢焦点、不请求无边框捕获权限，不保存或上传截图；系统未保留画面时显示预览不可用，并允许后续重试。
- 灵动岛的临时提示复用 Dock 已有的应用名称、图标、窗口匹配及系统注意请求，以及已有的电源、音乐和专注状态；只在本机进程内传递，不保存事件历史或同步给伴随屏。系统注意请求不包含消息正文，也不代表具体未读数量；点击提示只激活匹配的已有窗口。不会为这些提示读取通知数据库、对话、凭据或新增通知权限。
- Codex 额度通过已安装的官方 CLI 执行只读 `account/rateLimits/read` 请求。认证由 CLI 管理，组件不拷贝或解析登录文件，不发送模型请求；本地缓存仅用于显示最近额度。该接口和 CLI 安装位置可能随官方版本变化。
- 天气由桌面和伴随屏共用的采集器向 `api.open-meteo.com` 请求已配置的经纬度，优先选择中国气象局 CMA GRAPES 模式，失败时回退到同服务的综合预报；不向中国气象局直接请求，也不要求账号或密钥。成功后约 15 分钟刷新，失败后至少等待 60 秒再试；各显示页面共用请求与本机 `LiquidDesktop/weather-cache.json`，不重复采集。数据属于模式估计，界面显示来源和更新时间，过期时明确提示。
- 设置中的城市搜索只在点击搜索时向 `geocoding-api.open-meteo.com` 发送输入的城市名，不读取系统定位或通过 IP 定位。所选城市名称与坐标保存在本机 `LiquidDesktop/weather-location.txt`，天气缓存也包含所选位置，均不随安装包分发。旧天气城市与坐标在用户选择前保持不变；网络不可用时可显示最近两小时内的上次数据，超过两小时不再当作当前天气。公开服务的使用条件以提供方说明为准。
- 天气和城市搜索使用请求自身的直连设置。只有传输失败或超时时，向 [阿里公共 DNS](https://www.alidns.com/)（`dns.alidns.com`，引导地址 `223.5.5.5`）或 [Cloudflare DNS over HTTPS](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/)（`cloudflare-dns.com`，引导地址 `1.1.1.1`）发送上述两个公开 API 域名的 A 记录查询；不向解析服务发送城市、坐标或完整天气 URL。只接受公网 IPv4，拒绝 `198.18.0.0/15` 虚拟地址，内存解析缓存不超过记录 TTL 或五分钟。重试仍访问原 Open-Meteo HTTPS 服务；Windows 的请求级解析覆盖保留原主机与证书验证，不修改系统代理、DNS、hosts、网络路由或 VPN。正常请求超时为六秒。恢复共用十秒预算，首个解析器及其地址最多使用前六秒。首组地址均连接失败后，才查询第二个解析器并尝试尚未使用的地址。每次解析与原生连接阶段最多分配两秒，同步阶段返回时检查剩余预算。HTTP 429、服务端错误不触发解析恢复；城市搜索取消后不启动后续请求。独立 Rainmeter 天气卡改为读取同一份本机快照，不再重复向公网采集。
- 可选网易云音乐桥接会读取音乐窗口标题及本机播放队列，并从音乐服务的封面地址获取图片。只有安装时选择 `-EnableMusicBridge` 才启动；没有选择时音乐桥接不运行。
- Dock 歌词有独立开关，默认关闭；开启显示、展开桌面音乐面板或使用已授权的伴随屏音乐时，通过系统 SMTC 读取当前播放元数据与进度，写入本机 `music-data/session.json`。当前系统媒体缩略图供音乐卡片和背景取色使用，生成的 `session-cover-*.bin` 缓存最多保留 8 张，每张读取上限 2 MiB；不修改播放器自己的封面文件。上述使用条件均结束或本机宿主进程退出后停止媒体读取器。
- 网易云 Windows 3.1.41.205529 未提供 SMTC 时，歌词适配器核对版本与模块大小后，以只读权限每约 400 毫秒读取播放进度和时长两个 8 字节数值，并用本机队列校验歌曲时长。没有内存扫描、代码注入或进程写入；其他版本不尝试这些偏移。临时状态写入 `music-data/netease-session.json`，上述媒体使用条件均结束或退出时停止读取并移除该临时状态。
- 歌词在线匹配另行开启，默认关闭。LRCLIB 接收歌曲标题、歌手、专辑与时长；网易云来源可读取本机播放队列以精确匹配歌曲 ID，再向网易云歌词接口发送该 ID。不读取 Cookie、令牌或登录凭据，不上传整个队列、壁纸或其他窗口数据。在线开关关闭后不发起新歌词请求，并丢弃尚未完成请求的结果。
- 同步歌词保存在本机有数量与大小限制的缓存中（最多 32 首）；设置和状态文件位于安装目录。退出后这些本地文件保留，供后续手动开启使用；删除缓存前先退出美化。服务提供方的歌词权利与使用条件不因本仓库 MIT 许可证改变。
- QQ 音乐使用相同的本机系统媒体会话读取元数据、进度和封面，不读取 QQ 登录信息、Cookie、加密数据库或进程内存。播放控制只向对应媒体会话提交固定动作。仅在在线歌词已开启时，向 `u.y.qq.com` 发送歌曲名和歌手进行匿名搜索，结合专辑和时长在本地筛选，再向 QQ 请求候选歌曲详情；确认唯一版本后向 `c.y.qq.com` 发送歌曲 ID 获取原曲同步歌词。不上传 QQ 账号或播放队列，不将 QQ 未确认版本回退为 LRCLIB 相似匹配。桌面与已授权伴随屏共用查询结果与有上限的本地缓存。
- 歌词背景取色使用本机已有专辑封面或当前壁纸，切歌时更新配色。背景配色功能不发送封面、壁纸或取色结果，不为背景效果单独联网下载图片；未取得封面时回退到壁纸。原有可选音乐桥接和在线歌词的联网范围仍按各自开关控制。
- 运行窗口枚举、本地桌面快捷方式和壁纸采样均供桌面功能使用；这些内容没有遥测上传功能。
- 每屏壁纸采样保存在安装目录的 `LiquidDesktop/wallpaper-monitor-*.png`，供对应屏幕的玻璃读取；这些私人背景缓存不进入安装包。
- 安装器只有点击并确认“一键补齐缺失组件”后才从 Rainmeter 或 Microsoft 官方源下载组件；Rainmeter 校验固定 SHA-256，Microsoft 安装包校验有效数字签名和发布者。下载临时文件完成或失败后清理，独立组件按各自许可安装；静默安装不自动下载。启动失败记录保存在本机 `LiquidDesktop/startup-error.log`，可能含本机路径，不自动上传。
- 本仓库的构建会请求 NuGet；打开用户自己保存的链接会交给默认浏览器处理。
- 「检查更新」请求本仓库的 GitHub 最新正式版本信息。关闭自动更新时，只在用户主动检查时请求，可从浏览器打开官方发布页。手动开启自动更新后，会定时检查并限速下载安装器。安装前再次核对官方 GitHub 资产和 SHA-256，空闲时执行覆盖安装。请求不含配对信息、桌面路径、壁纸或 GitHub 登录凭据。下载、更新状态和失败恢复文件均在本机保存。
- 独立副屏仅在点击「打开副屏」后启用受支持的虚拟显示目标，停止或失联心跳过期时关闭。为恢复普通桌面排列，临时把图标路径与坐标保存到本机 `runtime-data/companion/virtual-display-icons.json`，不会通过网络发送；成功恢复后删除，失败则保留供本机恢复。
- iPad 伴随屏默认不监听，需手动开启精确局域网入口上的 HTTPS 服务。开启后可在 PrismGlass 桌面退出期间继续使用。从伴随屏管理页或 Windows 托盘可以单独结束监听。Windows 注销和进程退出也会结束监听。配对码短时有效，电脑确认后设备获得可撤销的会话；有效会话每天使用时可续期至 30 天，连续 30 天未使用会失效。续期不增加共享权限；各项共享权限默认关闭。配对记录在 `runtime-data/companion/devices.bin` 使用当前 Windows 用户 DPAPI 保护，共享应用范围位于 `runtime-data/companion-settings.json`，均不得打包或提交。
- 主屏幕窗口内的“扫码配对”只在主动点击后请求相机权限，最多使用 60 秒；画面由随包附带的 jsQR 在 iPad 内处理，不上传或保存。只接受当前 HTTPS 来源的短期配对二维码，不跳转扫描到的网址；识别、取消或切后台立即停止相机。麦克风和定位保持禁止。首次配对仍需电脑批准，Safari 与主屏幕窗口各自保留会话。
- 获得基础共享授权的伴随屏可接收选定应用的名称、分类和小图标、音乐元数据/歌词/当前封面、待办及笔记。这些接口不会发送可反解的桌面应用 ID、文件路径、启动参数、窗口标题、Codex 额度或认证材料，也不传送壁纸文件或桌面截图。私人响应不缓存；浏览器后台、401、锁屏及连接超时会清空私人视图，但无法追回设备曾经接收的数据。
- 屏幕画面、键盘输入和触控板分别授权，默认关闭。另行配置并开始投屏后，会经局域网 WebRTC 发送选定整块显示器的实时画面，其中可能包括窗口、壁纸、通知及敏感内容；系统声音需另行授权和点按开启，不录制、不提供单软件隔离。使用本机另行配置的 FFmpeg 与 MediaMTX，无外部 STUN/TURN 或公网中继；停止、撤权、锁屏或心跳超时后停止采集。键盘将用户在 iPad 输入的文字与白名单按键发送到电脑当前窗口，不读取或同步剪贴板；写入失败不自动重试。详见 [投屏与输入说明](COMPANION-SCREEN.md)。
- 开机自启默认关闭；用户开启后只在当前账户的 Windows 启动目录创建本程序的快捷方式，关闭或卸载时移除。它不自动开启伴随屏服务或增加共享权限。
- 开始投屏时会检查视频防火墙规则；仅从已通过会话与屏幕权限校验的连接读取设备 IP，短时保存在进程内。修复前在电脑说明新旧地址和范围，确认后才更新配置中的 MediaMTX、当前专用网卡、UDP 31890 和该设备地址，不放开整个子网。取消不修改规则，不增加配对或共享权限。
- 伴随屏仅通过固定动作控制应用打开、媒体、音量、专注和有限主题设置；不接受任意命令或文件路径。无公网映射、上传下载或离线动作队列，不会自动启用已有歌词联网或媒体采集开关。HTTPS 部署脚本默认只预览，证书、URL ACL 和专用网络规则只有明确应用时才创建，详见 [伴随屏说明](COMPANION.md)。
- 触控启用后的前台保活仅维持既有控制租约，不产生输入；后台、断线或撤权时停止。顶部灵动岛只接收服务是否运行、近期连接数量、投屏与触控是否活动，不接收设备名称或 IP。近期在线时间只保存在进程内，不写入配对文件；停止远程操作保留配对和共享权限。

- 本地预览的系统声音权限默认关闭，用户明确允许后采集默认播放设备的回环声音，可能包含其他应用和通知；不请求麦克风。单独关闭声音保留视频；停止、锁定、撤权或失去声音续期后释放采集。音频通过现有局域网链路发送，不保存录音文件。
- 可选 NPU 文字提取仅由电脑端按钮触发，短暂隐藏设置窗口后采集该窗口所在屏幕的一帧。图片通过内存管道交给本机模型，识别文字仅保留在当前页面；离开或关闭会清除，复制按钮才将其写入 Windows 剪贴板。正常识别不联网、不保存截图或文本日志，也不自动扩大伴随屏权限。独立工具准备脚本会从 PyPI、RapidAI 的 ModelScope 发布和 Intel Open Model Zoo 下载依赖与固定模型；模型缓存保留，用户屏幕内容不进入编译缓存。

- 桌面照片由电脑端原生文件选择器明确选择，可同时添加最多六张 JPG/PNG 卡片。程序仅读取选中的文件并生成有尺寸上限、去除原始元数据的本地 PNG 副本，存于 `LiquidDesktop/photo-cards`；不保存原图路径，不扫描照片目录，不上传。换图失败保留旧副本，移除只删除该卡片的导入副本，原照片不变。缩略图只通过现有可信桌面 WebView 的本地资源路径显示，伴随屏 HTTP 服务不提供此目录的图片或记录。已有用户主动开启的屏幕投送仍按既定屏幕权限显示实际桌面。
