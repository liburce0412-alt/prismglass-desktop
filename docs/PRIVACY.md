# 本地数据与网络请求

- WebView2 只承载本机组件页面，运行目录在安装位置的 `LiquidDesktop/runtime-data`。
- 笔记、事项、链接、生态瓶、可见性、应用固定配置和运行状态均保存在本机安装目录。不要把运行目录整体提交到 Git。
- 应用中心读取用户/公共桌面、用户/公共开始菜单和 Shell 已安装应用目录；手动添加时仅收录用户所选路径。名称、目标、启动参数、来源、分类、单层文件夹、别名与排除记录保存在 `LiquidDesktop/app-library.json`，不进行全盘搜索或上传。图标通过本机 Shell 提取，拼音索引使用随包分发的离线 Unicode 数据。
- 统一设置保存在 `LiquidDesktop/desktop-settings.json`，继续与原有歌词、侧栏和组件状态文件共用数据。显示器设备标识用于恢复各屏配置；注册的唤起快捷键在退出时释放。诊断可能包含组件位置、暂停原因、应用路径和窗口标题，分享日志前应自行查看。
- Codex 额度通过已安装的官方 CLI 执行只读 `account/rateLimits/read` 请求。认证由 CLI 管理，组件不拷贝或解析登录文件，不发送模型请求；本地缓存仅用于显示最近额度。该接口和 CLI 安装位置可能随官方版本变化。
- 天气皮肤向 Open-Meteo 请求安装时设置的经纬度，网络不可用时数据显示可能过期或缺失。公开服务的使用条件以提供方说明为准。
- 可选网易云音乐桥接会读取音乐窗口标题及本机播放队列，并从音乐服务的封面地址获取图片。只有安装时选择 `-EnableMusicBridge` 才启动；没有选择时音乐桥接不运行。
- Dock 歌词有独立开关，默认关闭；开启显示、展开桌面音乐面板或使用已授权的伴随屏音乐时，通过系统 SMTC 读取当前播放元数据与进度，写入本机 `music-data/session.json`。当前系统媒体缩略图供音乐卡片和背景取色使用，生成的 `session-cover-*.bin` 缓存最多保留 8 张，每张读取上限 2 MiB；不修改播放器自己的封面文件。上述使用条件均结束或桌面进程退出后停止媒体读取器。
- 网易云 Windows 3.1.41.205529 未提供 SMTC 时，歌词适配器核对版本与模块大小后，以只读权限每约 400 毫秒读取播放进度和时长两个 8 字节数值，并用本机队列校验歌曲时长。没有内存扫描、代码注入或进程写入；其他版本不尝试这些偏移。临时状态写入 `music-data/netease-session.json`，上述媒体使用条件均结束或退出时停止读取并移除该临时状态。
- 歌词在线匹配另行开启，默认关闭。LRCLIB 接收歌曲标题、歌手、专辑与时长；网易云来源可读取本机播放队列以精确匹配歌曲 ID，再向网易云歌词接口发送该 ID。不读取 Cookie、令牌或登录凭据，不上传整个队列、壁纸或其他窗口数据。在线开关关闭后不发起新歌词请求，并丢弃尚未完成请求的结果。
- 同步歌词保存在本机有数量与大小限制的缓存中（最多 32 首）；设置和状态文件位于安装目录。退出后这些本地文件保留，供后续手动开启使用；删除缓存前先退出美化。服务提供方的歌词权利与使用条件不因本仓库 MIT 许可证改变。
- QQ 音乐使用相同的本机系统媒体会话读取元数据、进度和封面，不读取 QQ 登录信息、Cookie、加密数据库或进程内存。播放控制只向对应媒体会话提交固定动作。仅在在线歌词已开启时，向 `u.y.qq.com` 发送歌曲名和歌手进行匿名搜索，结合专辑和时长在本地筛选，再向 QQ 请求候选歌曲详情；确认唯一版本后向 `c.y.qq.com` 发送歌曲 ID 获取原曲同步歌词。不上传 QQ 账号或播放队列，不将 QQ 未确认版本回退为 LRCLIB 相似匹配。桌面与已授权伴随屏共用查询结果与有上限的本地缓存。
- 歌词背景取色使用本机已有专辑封面或当前壁纸，切歌时更新配色。背景配色功能不发送封面、壁纸或取色结果，不为背景效果单独联网下载图片；未取得封面时回退到壁纸。原有可选音乐桥接和在线歌词的联网范围仍按各自开关控制。
- 运行窗口枚举、本地桌面快捷方式和壁纸采样均供桌面功能使用；这些内容没有遥测上传功能。
- 本仓库的构建会请求 NuGet；打开用户自己保存的链接会交给默认浏览器处理。
- iPad 伴随屏默认不监听，需每次手动开启精确局域网入口上的 HTTPS 服务。配对码短时有效，电脑确认后设备获得可撤销的会话；有效会话每天使用时可续期至 30 天，连续 30 天未使用会失效。续期不增加共享权限；各项共享权限默认关闭。配对记录在 `runtime-data/companion/devices.bin` 使用当前 Windows 用户 DPAPI 保护，共享应用范围位于 `runtime-data/companion-settings.json`，均不得打包或提交。
- 主屏幕窗口内的“扫码配对”只在主动点击后请求相机权限，最多使用 60 秒；画面由随包附带的 jsQR 在 iPad 内处理，不上传或保存。只接受当前 HTTPS 来源的短期配对二维码，不跳转扫描到的网址；识别、取消或切后台立即停止相机。麦克风和定位保持禁止。首次配对仍需电脑批准，Safari 与主屏幕窗口各自保留会话。
- 获得授权的伴随屏可接收选定应用的名称、分类和小图标、音乐元数据/歌词/当前封面、待办及笔记。不会发送可反解的桌面应用 ID、文件路径、启动参数、窗口标题、Codex 额度、认证材料、壁纸或桌面截图。私人响应不缓存；浏览器后台、401、锁屏及连接超时会清空私人视图，但无法追回设备曾经接收的数据。
- 伴随屏仅通过固定动作控制应用打开、媒体、音量、专注和有限主题设置；不接受任意命令或文件路径。无公网映射、上传下载或离线动作队列，不会自动启用已有歌词联网或媒体采集开关。HTTPS 部署脚本默认只预览，证书、URL ACL 和专用网络规则只有明确应用时才创建，详见 [伴随屏说明](COMPANION.md)。
