# 验证概述与已知边界

整理日期：2026-10-27。本页摘录 2026-10-25 至 2026-10-27 已有的本地检查记录，说明使用过的方法、实际结果和范围；下方历史结果不是本版重新实测，当前版本的新增检查单独列出，也不表示全部环境均已验收。后续版本只复用代码及相关条件未改变的结果，其余结果需针对相应版本更新。

## 0.9.0-beta.1 发布检查

2026-10-27 针对待发布源码重新运行完整 `scripts/Test.ps1`，行为与语法检查通过。包括 Dock 交互 55 项、真实路径身份 9 项、显示器激活/命令 23 项、安装集成 50 项、轮廓消息 25 项、Dock/歌词过渡 22 项及窗口预览生命周期 7 项，以及应用库、设置、歌词和伴随屏服务/网页检查。

安装集成检查使用隔离目录与模拟依赖，覆盖皮肤归属、自定义路径、配置保留、重复卸载、拒绝越界文件清单、首次目录刷新标记与私有文件打包拦截。Windows 主程序和 Inno Setup 6.7.3 安装器编译通过；发布制品从对应源码提交的干净快照构建，不压缩正在使用的安装目录。

检查中发现临时拖拽反馈文件被读取时，替换失败可能中断操作。已加入真实文件共享占用回归并修复：下次 Tick 重试，成功后才更新去重状态；取消时仍释放租约。若清空受阻，旧反馈按已有两秒租期失效。正式配置保存失败仍报告，不吞掉用户数据写入错误。

这些结果不包括真实图形安装/升级/卸载、跨电脑使用或新版 iPad 全部功能实测。未修改正式桌面安装、未执行真实鼠标/电源控制、未为测试改变网络规则。已知限制和下载说明见 [本版说明](RELEASE-0.9.0-beta.1.md)。

## 尚未覆盖与反馈

尚未全面实测的范围包括：干净 Windows 安装与完整卸载、其他电脑和用户目录、物理屏幕拔插、完整系统重启与电源事件、不同播放器的持续播放、长期性能，以及当前伴随屏在不同 iPad 和网络中的触控、软键盘、GPU 与耗电表现。

未实测不等于失败，也不要求新增设备或安排外部测试人员。面向通用环境设计，在现有条件下检查，后续通过实际使用反馈补充。已确认的启动失败、数据损坏和桌面无法恢复等严重问题仍需修复并复查，不能以尚待反馈为由忽略。

反馈可提交到 [GitHub Issues](https://github.com/liburce0412-alt/prismglass-desktop/issues)，注明软件版本、Windows 版本、相关显示器与缩放、复现步骤、预期和实际结果。日志和截图可选，上传前检查并移除私人笔记、账号、路径、配对密钥和证书私钥；不要上传整个运行目录。详见 [隐私说明](PRIVACY.md)。
