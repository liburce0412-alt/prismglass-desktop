## 0.9.1 桌面与伴随屏检查

2026-10-28，本地完整行为与语法回归通过。新增登录启动检查在隔离目录创建真实 Shell Link，并验证默认关闭、路径归属及 Windows 禁用状态；没有为测试启用实际登录启动项。离屏 WebView2 设置、天气、应用和壁纸反馈共 46 项检查通过，另有 16 项应用拖动检查。

- 更新的正式程序原位安装成功，启动前核对 64 份个人设置与配对文件保持一致。直接打开 EXE 能通过完整启动流程；本机美化就绪后原生图标隐藏，退出时恢复。壁纸采样实际更新并被渲染器接收，系统壁纸路径保持不变；自启读回关闭。
- 天气完整所属地区和同名居民点检查通过，并核对了实际城市查询；没有替用户猜测或更改所在城市。
- 真实 iPad Air 2 / iPadOS 14.2 用户确认全屏及原生键盘正常；专用记事本实际收到完整中文测试内容。Safari 14 全屏样式和断线后残留只读超时提示均经实机验证。权限、输入校验、去重、撤销与投屏心跳等使用隔离测试覆盖；详见 [投屏检查](COMPANION-SCREEN.md)。
- 720p 短时采样约 30.02 fps，主屏 1080p 约 30.03 fps；虚拟显示器独立扩展成功并保留原主屏关系。Safari 14 未提供解码丢帧字段，不能据网络丢包样本声称零解码丢帧。

未重启 Windows 验证登录自启，未在干净电脑重演全部依赖安装，未覆盖其他硬件、端到端触摸延迟、持续数小时稳定性和功耗。安装包仍未签名。屏幕串流依赖额外的 FFmpeg/NVIDIA 编码与 MediaMTX 配置，不是所有电脑安装后都能直接投屏。

## 尚未覆盖与反馈

尚未全面实测的范围包括：干净 Windows 上从零安装依赖及卸载、其他电脑和用户目录、物理屏幕拔插、完整系统重启与电源事件、不同播放器的持续播放、长期性能，以及当前伴随屏在不同 iPad 和网络中的触控、软键盘、GPU 与耗电表现。本机现有依赖下的原生安装、升级与卸载结果见上方当前版本记录。

未实测不等于失败，也不要求新增设备或安排外部测试人员。面向通用环境设计，在现有条件下检查，后续通过实际使用反馈补充。已确认的启动失败、数据损坏和桌面无法恢复等严重问题仍需修复并复查，不能以尚待反馈为由忽略。

反馈可提交到 [GitHub Issues](https://github.com/liburce0412-alt/prismglass-desktop/issues)，注明软件版本、Windows 版本、相关显示器与缩放、复现步骤、预期和实际结果。日志和截图可选，上传前检查并移除私人笔记、账号、路径、配对密钥和证书私钥；不要上传整个运行目录。详见 [隐私说明](PRIVACY.md)。
