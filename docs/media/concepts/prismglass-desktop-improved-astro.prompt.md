## 初始生成提示词

Use case: ui-mockup. Create ONE polished, high fidelity concept image for the redesigned PrismGlass Windows desktop, based on an existing product whose signature is refractive liquid glass, an Astro theme, a compact top island, side widgets, a terrarium garden and a bottom application Dock. This is a new proposed UI, not a photograph and not an advertisement.

Composition: widescreen 16:9 desktop screenshot, preferably 2560x1440 or greater, straight-on flat pixels, edge-to-edge wallpaper, no monitor bezel, no perspective device mockup, no presentation board, no marketing headline. The central application launcher is the primary focus. Use ample negative space. Make it look like a coherent, beautifully engineered desktop someone could use all day.

Wallpaper: sophisticated midnight navy and slate blue flowing hills, restrained cyan and muted lavender aurora near the horizon, sparse tiny stars. The wallpaper is gentle and low contrast beneath labels, with no busy space imagery. Glass materials have softly blurred background, optically rounded edges with fine cyan/lavender refraction, restrained bright edge highlights, soft realistic shadows. White and light slate text must be crisp and readable. No neon cyberpunk, no excessive bloom, no bulky opaque dashboard cards.

Layout:
1. A slim floating translucent top bar inset 28 px from the screen edges. Left: a small prismatic diamond mark and "PrismGlass". Center: compact now-playing island with a tiny waveform, text "光落在此刻", a pause symbol; this is an original demo track name. Right: Wi-Fi, battery "86%", time "12:27", date "10月25日", and a simple settings gear icon clearly accessible. No big top branding.
2. A beautifully proportioned central application center, about 62% of screen width and 60% of height, one rounded glass surface. Header left "应用中心"; top right a small quiet "添加" button and close glyph. Below header a large calm search field with magnifying glass, exact placeholder "搜索应用、文件和操作" and a small keyboard shortcut glyph badge. Below it one row of compact category tabs: "全部", "游戏", "学习", "工作", "娱乐", "未分类". Select "全部" with a restrained luminous blue glass pill.
3. In this launcher show an orderly 6-column by 2-row grid of well-crafted recognizable colorful application icons with consistent optical size and generous spacing. First row labels: "Edge", "VS Code", "Steam", "微信", "网易云音乐", "Figma". Second row: four-icon folder tile "学习资料", four-icon folder tile "创作工具", "文件", "终端", "笔记", "计算器". Use authentic-looking logos where known, clear friendly line icons for utilities, rounded translucent folder tiles with a small 2x2 preview. All labels single-line, aligned, high contrast, readable. Tiny centered pagination "1 / 2" with chevrons at bottom. No edit badges, no busy controls.
4. Narrow quiet glass icon rails near the left and right edges, three or four simple icons each, aligned and generously spaced. Left rail weather, music, focus, garden. Right rail notes, files, tools, settings. Near lower left, outside launcher, ONE small persistent glass garden widget with a tasteful transparent terrarium containing a delicate green fern, label "生态瓶", secondary text "慢慢生长". It is small, refined, not a huge illustration. All remaining widgets stay collapsed.
5. A compact bottom-center floating Dock, separated from launcher by breathing space, with 8 recognizable application icons: application grid, file explorer, Edge, VS Code, music, WeChat, Steam, settings. A subtle separator distinguishes system entry from apps. Small running dots under selected applications. Glass Dock edge bulges gently around a hovered icon, subtle and physically credible. Keep icons sharply rendered, not stretched. No Windows taskbar behind it.
6. At the very bottom right put a small discreet caption "PrismGlass · 概念设计" to label the image as a concept.

Design goals: centralized searching and category browsing, visual calm, compact regular spacing, unified interaction vocabulary, crisp Chinese typography similar to Microsoft YaHei UI or Source Han Sans. Preserve PrismGlass's distinctive liquid glass, music island and terrarium identity while making the interface visibly cleaner. Only the application center is an expanded foreground panel; do not show a settings window simultaneously. No browser chrome, no Douyin UI, no unrelated personal data, no fake performance numbers, no arrows or explanatory callouts.
