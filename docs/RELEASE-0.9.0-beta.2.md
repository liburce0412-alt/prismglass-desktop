# PrismGlass Desktop 0.9.0-beta.2

修复首次安装后的启动失败，并提供中文安装向导。建议新用户直接下载本版；已安装 beta.1 的用户先退出 PrismGlass，再用本版安装器覆盖升级。

## 下载与安装

下载 `PrismGlass-Setup-0.9.0-beta.2-x64.exe`，面向 Windows 10/11 x64。普通用户无需开发工具。向导检查 Rainmeter、PowerShell 7、WebView2 Evergreen Runtime 和 .NET Framework 4.8，缺少时提供官方下载入口。

- 安装、依赖选择、卸载与错误提示改为中文。
- 默认接受许可，桌面只创建一个 **PrismGlass** 图标，完成页默认勾选启动；可以在向导中取消。退出使用托盘或开始菜单。
- 静默安装支持指定现有 Rainmeter 和 PowerShell 路径，不自动开启美化，失败仍中止。
- 不改变登录启动或伴随屏网络权限，覆盖升级保留个人配置。
- QQ 音乐通过系统媒体会话接入歌曲、封面与进度；音乐卡片显示系统封面，桌面与伴随屏的播放控制使用对应会话。在线歌词核对完整歌曲版本后，按 QQ 歌曲 ID 获取原曲同步歌词；桌面与伴随屏共用结果。无法唯一确认时不强行匹配，旧 QQ 歌词缓存不会绕过新版确认。

## 修复与检查

beta.1 的首次皮肤刷新使用 PowerShell 的旧退出码判断 GUI 程序，可能把尚未返回的退出码视为失败。现在等待这次 Rainmeter 命令完成并读取它自己的退出码；只有真实失败才中止。修复后已在本机实际完成首次启动和正常退出，组件就绪且 Windows 任务栏恢复。

具体安装、升级、卸载与回归检查范围见 [验证概述](VALIDATION.md)。本机检查不代表其他电脑、全部屏幕组合及新版 iPad 功能均已实测；兼容性继续依据实际反馈完善。

## 已知边界

- 免费 MIT 开源，安装包未签名；附 SHA-256 校验文件，不要求关闭安全软件。
- 旧手工部署默认不会自动迁移，未归属目录与皮肤仍受保护；不要删除原数据强行安装。
- 卸载保留个人设置及伴随屏配置记录，不移除共享依赖或系统网络配置。
- 天气仍使用示例位置，安装器暂无城市选择；没有常驻自动更新服务。
- 当前 iPad 主屏幕内扫码、重开连接、真实触控/滚轮和长期运行仍待设备使用反馈。

问题请提交到 [GitHub Issues](https://github.com/liburce0412-alt/prismglass-desktop/issues)，附版本和复现步骤。不要上传完整运行目录、配对密钥、证书私钥或个人笔记。
