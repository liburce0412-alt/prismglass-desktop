# Desktop widget visuals

The optional native Rainmeter cards are `BreathingOrb`, `DigitalClock`, `Moon`, and `Photo`. Existing widget IDs, saved placements, theme and pause settings remain intact; Starlight and MoodNote are retired. BreathingOrb, DigitalClock and Moon keep 244×196 bounds. Photo cards fit the selected image aspect ratio, with a 280 px long image edge and a thin rounded margin; all avoid permanent operation captions. New cards are disabled until chosen or explicitly added.

`BreathingOrb` uses the original transparent `aurora-orb.png`, generated with the built-in imagegen tool on 2026-11-07. Keep its alpha channel. Its artwork moves within a fixed input meter; the mouse hit target and tooltip do not move with the breathing image. Animation uses elapsed time at a requested 16 ms interval, falling back to approximately one-second updates while paused. This is an update target, not a measured frame-rate guarantee.

`DigitalClock` uses native local Time measures, with white digits and a quiet colon directly above the shared glass. The previous dark split plates are removed so the clock reads as one continuous transparent card. It has no flip animation or bundled FlipClock code/assets. Rounded modules and restrained text follow [Apple's macOS widget guidance](https://support.apple.com/en-au/guide/mac-help/mchl52be5da5/27/mac/27).

`Moon` uses NASA's [Lunar Near Side](https://science.nasa.gov/resource/lunar-near-side/), credited to NASA/Goddard Space Flight Center/Arizona State University. The bundled 512 px JPEG was delivered by NASA's own image service without local pixel edits. A north-up round clip and computed illumination mask are drawn at runtime. Its former dark rectangular night backing is removed; the lunar disk and sparse stars sit directly on shared glass. Illumination adapts SunCalc 1.9.0 (BSD-2-Clause); waxing/waning uses ecliptic longitude. It is an hourly local estimate, not live photography, observer-specific orientation, eclipse prediction, libration or terrain shadow simulation. See `licenses/NASA-Lunar-Near-Side.txt` and `licenses/SunCalc-BSD-2-Clause.txt`.

`Photo` and `Photo2`–`Photo6` are six independent native windows sharing `Photo.inc` and `Photo.lua`. Settings → Desktop components → Photos offers a native multi-select JPG/PNG picker, thumbnails, per-card visibility/occlusion switches, replacement and removal. Each explicitly picked image is checked before decoding (25 MB, 24 megapixels, maximum dimension 12000, aspect ratio from 1:4 to 4:1), rotated using EXIF orientation, then copied locally with a maximum 1280 px edge. The displayed card follows that aspect ratio without cropping beyond rounded corners. Metadata and generated PNG copies live in `LiquidDesktop/photo-cards`; no original path is retained and deleting a card never deletes its source photo. Replacement failures preserve the old copy, and replacing a hidden card preserves its visibility choice. Existing `Photo` placement and legacy wallpaper preview remain until the user adds a photo. Double-click opens component settings; an empty card also offers an add-photo prompt. Missing files retain a visible fallback at the saved aspect ratio. Images are served only through the existing trusted desktop WebView mapping; the companion HTTP static whitelist excludes this folder.

Native foreground previews from an isolated Rainmeter profile are `artifacts/tests/ambient-*.png`. Their fallback material is not the complete installed WebGL glass composition.

## Original orb generation prompt
### aurora-orb.png

Use case: stylized-concept. Production desktop widget art asset, no UI and absolutely no text. A breathtaking luminous aurora orb, hand-crafted premium 3D abstract glass sculpture, one large spherical form centered, intensely luminous cyan mint and pale ice-blue center flowing into lavender and rich iris-violet edges, delicate translucent silk folds and swirling caustics inside, a fine pearlescent rim, beautiful smooth volumetric gradients and a soft coloured glow. Shape must read as one elegant light-filled orb with exquisite depth at only 150 pixels wide; no little balls, no cartoon emoji, no clipart, no other objects. Perfectly square transparent PNG cutout with generous transparent margin. The orb fills 76% of the square, its halo fades to complete transparency. No hard rectangular backdrop, no ground plane, no border, no lettering, no watermark. Polished Apple-like editorial art direction without any Apple logo.
