# PrismGlass 桌面整体改进方案

编写日期：2026-10-25
状态：对应功能已进入本地实现与验证；实际方法、结果和边界见 [公开验证概述](VALIDATION.md)。下列清单保留设计覆盖范围，不表示各项已经完成实机验收。

本文将设置、启动台、搜索、拖拽、布局、多屏和运行策略纳入同一套完整改进范围，按功能组织，不划分实施阶段或交付批次。各部分共同构成一次整体体验改进。

## 改进目标

让 PrismGlass 在保留液态玻璃、Dock 歌词、Sky / Astro、生态瓶和桌面组件的同时，更整洁、更容易找到功能，也更适合长期使用。

完成后的主要操作应连贯一致：用户可以通过 Dock 或快捷键打开应用中心，用分类浏览或搜索找到项目，直接拖到 Dock 固定；所有外观、组件、歌词和操作习惯在同一个设置中心管理；连接显示器、进入全屏、锁屏和恢复桌面时，布局与动效按明确规则变化。

本方案沿用当前 C# WinForms、WebView2、WebGL 和 Rainmeter 架构，复用现有图标读取、应用启动、窗口预览、消息桥、设置保存与恢复机制。现有权限、网络功能开关和默认手动开启方式保持有效。

## 当前基础与改进范围

以下现状来自本次源码检查；它们说明当前实现结构，不代表本轮已经完成实机验证。

| 范围 | 当前基础 | 本次改进要求 |
|---|---|---|
| 设置 | 组件与鼠标有管理界面；歌词位于音乐面板，主题与暂停位于顶栏，Dock 操作位于右键菜单 | 提供统一的 PrismGlass 设置中心，并保留常用场景中的快捷入口 |
| 应用入口 | 用户桌面与公共桌面合并为图标网格；“全部应用”打开 Windows AppsFolder | 建立可浏览、可搜索、可整理的应用中心 |
| 搜索 | 文件浏览器支持当前文件夹名称筛选 | 统一检索已收纳的应用、文件、文件夹及既有系统动作 |
| Dock | 固定应用与运行窗口、DWM 窗口预览、遮挡隐藏和边缘唤出已经存在 | 增加直接拖排、拖入固定、清晰的落点与取消反馈 |
| 视觉与动效 | 双主题、共享玻璃渲染、悬停形变、歌词字效与生态瓶已经存在 | 统一布局、文字层级、控件状态和收放行为，保留已有视觉表现 |
| 显示器 | 已有 DPI 校正；整体布局仍由主屏幕驱动 | 支持显示器选择、每屏组件配置、插拔与缩放变化恢复 |
| 资源策略 | 已有手动暂停、覆盖时暂停、动画静止停绘和部分数据降频 | 补齐会话、电源和每屏可见性策略，明确恢复条件 |
| 数据与恢复 | 已有部分配置原子保存、笔记冲突保护、退出恢复和有限故障重试 | 将这些约束覆盖到新增配置、分类、布局和交互 |

## 整体界面结构

| 界面 | 承担的任务 | 展示原则 |
|---|---|---|
| 顶部栏 | 状态、当前媒体、专注、暂停入口和设置入口 | 常态保持紧凑，详细信息按需展开 |
| 底部 Dock | 常用应用、运行窗口、应用中心入口与既有歌词显示 | 固定入口、运行状态和操作反馈清楚，不重复堆放全部应用 |
| 应用中心 | 搜索、分类、文件夹、应用与文件启动 | 搜索和分类固定在上部，图标区负责浏览，管理操作按需出现 |
| 两侧组件 | 天气、音乐、专注、笔记、生态瓶等现有工具 | 允许用户隐藏与调整排列；收起状态保留简短且可辨识的入口 |
| 设置中心 | 外观、组件、应用中心、Dock、歌词、快捷操作、显示器、运行策略 | 使用一致的导航与控件，设置有当前值、保存反馈和局部恢复默认 |

同一时间只保留一个需要键盘输入的前台面板。打开应用中心或设置中心时，关闭无关的临时悬浮面板；已固定的组件状态仍由用户控制。Esc 按交互层级退出；点击面板外部收起最外层临时面板，有菜单时先关闭菜单，拖动和模态对话框期间不触发外部点击收起。

## 功能与交互要求

### 统一设置中心

- 顶栏“PrismGlass 设置”和现有“管理”入口进入同一界面；Windows 设置另以明确名称保留，避免齿轮含义混淆。
- 设置页面覆盖外观、组件、应用中心、Dock、歌词、快捷操作、显示器和运行策略。音乐面板中的歌词快捷调节与设置中心使用同一份状态。
- 复用现有设置对象与保存方式，统一入口不要求重写所有配置文件。界面订阅同一状态，避免两个入口互相覆盖旧值。
- 外观修改即时预览并显示保存结果；保存失败时保留编辑值与错误提示。恢复默认只作用于当前设置页，不清空笔记、植物进度或应用库。
- 快捷键录制支持取消、清除、重复检测与注册失败提示；注册失败时保留原有可用绑定。
- 组件开关、排列、显示器归属与可见状态在一个位置管理。即使所有可选组件都隐藏，也应保留可访问的应用自身管理与退出入口。

### 应用中心、分类与文件夹

- 从当前显示器 Dock 上方向上展开，保持 16 物理像素间距，并限制在当前工作区内；设置中心首次居中，默认置顶，可拖动标题栏并记住本次运行的位置。尊重减少动效和暂停设置。
- 提供“全部”、内置“未分类”和用户可编辑的分类；可用游戏、学习、工作、娱乐、其他作为初始名称，用户可以增删、改名和排序。“未分类”保留稳定身份且不能删除，作为无归属项目的固定入口。
- 入口来源包括用户桌面、公共桌面、用户与公共开始菜单，以及用户主动添加的项目。通过受支持的 Windows Shell 入口处理商店应用，保留启动所需的身份信息。
- 分类保存的是入口归属，不通过移动、改名或删除原文件整理桌面。名称相同但目标不同的项目能够区分；同一入口从多个来源发现时合并展示。
- 同一入口只有一个主要分类，“全部”是聚合视图。手动归属优先于自动规则；没有可靠匹配时进入“未分类”，不凭猜测频繁改变归属。
- 分类内支持一层文件夹，支持创建、改名、拖入、拖出和内部排序。移除分类时，其项目进入“未分类”；移除文件夹时，其项目回到所属分类。原文件和应用保持不变。
- 拖动图标到另一图标中心并停留后，显示“创建文件夹”的明确预览；快速经过不建文件夹。离开落点或按 Esc 取消预览。
- 图标、分类、文件夹和页内顺序持久保存。调整网格密度或窗口大小后保留顺序，不丢失入口，也不将同一项目重复放到多个页。
- 项目较多时支持分页与滚动浏览。拖到翻页区域需要停留，并提供方向提示；一次持续停留只翻一页，避免连续跳页。
- 失效入口保留名称并显示不可用状态，允许重新定位或移除收纳记录，不自动删除对应分类或其他文件。

### 统一搜索与键盘操作

- Dock 的应用中心入口和用户配置的全局快捷键打开同一搜索界面；打开后聚焦输入框，保留中文输入法的正常输入与候选词确认。
- 搜索范围为应用库、用户收纳的文件与文件夹、当前已支持的系统动作。范围在界面上可理解，不把当前文件夹筛选表述成全盘搜索。
- 支持中文、英文、不区分英文大小写、拼音和首字母、别名及多个搜索词；结果按完整名称、前缀、缩写和模糊匹配的相关性排序。
- 结果展示名称、图标、类型或所属分类；同名项目补充路径或应用标识。界面给出无结果、加载中和入口失效状态。
- 方向键选择结果，Enter 执行，Esc 依次取消拖动或子对话框、返回上层、关闭主面板。焦点可见，Tab 顺序与视觉顺序一致。
- 搜索复用已有索引与图标缓存，合并连续输入；新查询使旧结果失效。关闭界面后停止无用查询，延迟返回的结果不能重新打开面板。
- 系统动作通过明确的动作标识进入现有命令分派；搜索文字与显示名称不直接拼接成命令执行。

### Dock 与窗口交互

- 支持直接拖动固定应用调整顺序，显示插入位置。拖动过程中暂不保存，松手确认后一次性提交，Esc 恢复原顺序。
- 从应用中心拖到 Dock 可固定入口；已固定项目定位到原项，避免重复。拖离 Dock 时清楚显示“取消固定”，不删除应用或源文件。
- 固定项和临时运行项保持可辨认的关系。运行窗口的出现、关闭与排序刷新，不覆盖用户正在进行的拖动。
- 保留当前真实窗口缩略图与激活能力，多窗口预览能够用鼠标和键盘选择。菜单、预览、拖动和应用中心开启期间保持 Dock 可操作。
- 保留遮挡隐藏与边缘唤出，隐藏区域与实际可见区域一致。关闭应用中心后恢复原来的常驻或隐藏状态，不突然抢占焦点。
- 图标放大使用足够清晰的图标源与缓存，按比例缩放。名称过长时截断并提供完整名称提示，图标留白与间距统一。
- 保留歌词收拢、靠近恢复图标、暂停或无有效歌词时恢复 Dock 的逻辑。拖动、菜单与窗口预览优先保证应用操作，结束后再按媒体状态恢复歌词。

### 视觉、布局与动效

- 设置中心、应用中心和现有组件共用玻璃材质、圆角、间距、文字与焦点样式，避免出现多套相互割裂的控件。
- 内容层级明确区分标题、主信息、说明和状态；深浅壁纸与 Sky / Astro 下均保证文字、选中状态和焦点可辨认。
- 玻璃透明度和文字可读性分别控制。调整透明度不应同时降低文字不透明度，也不能用整块页面透明来模拟玻璃。
- 保留当前折射、跟手高光、彩色流光、悬停放大、按压形变、图标弹跳、Astro 极光与流星、歌词字效和生态瓶表现。
- 展开、收起、翻页和拖动反馈支持连续操作。中途反向从当前状态继续，不跳到动画起点；视觉轮廓、窗口裁切和点击区域保持一致。
- 低频编辑操作集中在编辑状态、右键菜单或设置中；常态应用中心保留搜索、分类、图标与必要分页信息。
- 尊重系统减少动画和用户暂停选择。减少动画时保留清晰的状态变化与操作反馈，恢复后不补播暂停期间积累的动画。

### 多显示器与 DPI

- 设置中可选择 Dock 与组件所在显示器，并按屏幕保存启用状态与布局。未配置时沿用主屏幕默认布局。
- 使用稳定的显示器身份保存归属，显示顺序变化不应把配置错配到另一块屏幕。位置基于工作区和逻辑尺寸换算，保留已有 DPI 校正。
- 连接、断开显示器，以及修改分辨率、缩放或任务栏位置后，重新计算布局。弹出面板和窗口预览始终落在可用屏幕区域内。
- 屏幕断开时释放其显示实例；必要管理入口回到可用屏幕。保留断开屏幕的配置，重新连接时恢复，不把临时回退位置写成永久布局。
- 窗口覆盖、Dock 唤出和动画暂停按对应屏幕判断；一块屏幕上的全屏应用不无条件隐藏另一块屏幕的桌面组件。
- 多屏共享应用索引、媒体数据与配置服务，每屏只创建必要显示实例。Rainmeter 配置名、WebView 状态和消息路由明确所属屏幕，避免多个实例互相覆盖。

### 运行与省电策略

复用现有手动暂停、覆盖判断和静止停绘，统一管理暂停原因。只有所有适用的暂停原因解除后，相关动效才恢复；解除全屏不能覆盖用户主动暂停。

| 状态 | 目标行为 | 恢复条件 |
|---|---|---|
| 正常可见、用户正在交互 | 保留完整操作与所选效果 | 交互结束后进入正常空闲状态 |
| 面板关闭或所在屏幕被覆盖 | 停止不可见页面的持续绘制与无用任务；保留必要状态更新 | 页面重新可见，并且没有其他暂停原因 |
| 锁屏、屏幕关闭 | 暂停视觉渲染和无需继续的高频界面刷新 | 解锁或屏幕恢复，且用户未手动暂停 |
| 远程会话 | 按用户选择降低或暂停视觉效果 | 会话恢复本地状态，且其他条件允许 |
| 电池供电、系统节能 | 按设置降低非必要动画与刷新频率，应用启动和输入继续可用 | 电源状态恢复，或用户调整该项规则 |
| 用户手动暂停 | 保持暂停意图，不被窗口变化覆盖 | 用户明确恢复 |

- 设置界面显示当前暂停原因与对应规则，例如“已暂停动效：屏幕锁定”，区分暂停动效与暂停音乐播放。
- 优先响应系统和窗口事件；必须保留的轮询有明确用途与频率，隐藏或暂停时相应降频。
- 动画收敛后停止帧回调，窗口、图标和背景缓存保持容量限制；恢复时更新必要状态，避免集中补做过期请求。
- 本次调研没有同机性能实测，不能直接认定当前占用高或竞品更省资源。实现验收应比较同一机器、同一壁纸、同一效果和组件配置下的 CPU、GPU、内存与交互表现。

### 数据、兼容与恢复

- 新增设置提供默认值与版本兼容处理。升级保留现有 Dock 固定项、歌词设置、笔记、事项、链接、组件可见性和生态瓶进度。
- 分类、文件夹与排序以稳定入口标识关联，显示名称变化不导致归属丢失；文件目标身份不明确时保留待确认状态，不将旧归属错误转给同名新文件。
- 拖动、分类修改和布局保存作为完整操作提交，避免半完成状态。沿用现有原子保存与冲突保护，失败时显示具体错误并保持可恢复状态。
- 全局快捷键、目录监听、窗口事件和显示实例在退出时释放；退出仍恢复 Windows 原生桌面与任务栏。
- 组件启动失败、显示器变化或窗口恢复失败时，保留可访问的管理与退出入口，沿用有限重试及恢复模式。
- 保持开机普通桌面、用户手动开启美化的默认行为。歌词在线匹配等现有网络功能仍由既有独立开关控制。

## 整体验收标准

下列项目属于同一份设计覆盖清单。已有自动检查、隔离渲染与本机运行结果见 [公开验证概述](VALIDATION.md)；缺少验证的项目不作已验收标记，也不要求为完成清单新增设备或安排测试人员，其他环境由后续使用反馈补充。

- [ ] **设置一致性**：各设置入口指向同一状态；修改、失败提示、重新打开、重启与局部恢复默认均正确，既有用户内容保留。
- [ ] **应用来源与身份**：桌面、开始菜单、手动项目和商店应用可正确显示与启动；同名不同目标、重复入口、中文路径、失效项目处理明确。
- [ ] **分类与文件夹**：增删改名、排序、移出文件夹和分类移除后，项目仍可访问；源文件位置与内容保持不变，重启后归属一致。
- [ ] **搜索**：中文、英文、拼音、首字母、多个词和无结果均有正确行为；快速连续输入只显示最新查询结果，关闭后不被旧结果重新打开。
- [ ] **键盘与辅助操作**：全局快捷键可配置且冲突可见；中文输入法、Tab、方向键、Enter、Esc 与焦点提示正确，常用操作可在不使用鼠标的情况下完成。
- [ ] **拖动事务**：Dock 排序、拖入固定、跨分类、建文件夹和跨页拖动均有准确预览；取消不保存，快速经过不误建，松手不重复添加或丢失入口。
- [ ] **窗口与遮挡**：真实窗口预览、窗口选择、遮挡隐藏、边缘唤出、菜单及拖动锁定正常，退出面板后不抢焦点、不错误隐藏 Dock。
- [ ] **视觉与点击区域**：深浅壁纸、Sky / Astro、长名称和大字号下内容可读；动画期间视觉轮廓、窗口裁切与命中区域一致。
- [ ] **既有动效回归**：玻璃折射、跟手光、悬停/按压形变、图标弹跳、Astro、生态瓶和减少动画均保持预期行为。
- [ ] **歌词回归**：真实播放器的播放、暂停、切歌、前奏/间奏、长句、鼠标靠近、窗口预览与拖动操作之间切换正确；旧同步与保存能力保持可用。
- [ ] **多屏与缩放**：实机覆盖不同缩放比例、屏幕插拔、主屏切换和分辨率变化；组件归属正确、弹窗不出屏、恢复后布局不丢失。没有对应设备时明确保留该项未验收。
- [ ] **暂停与恢复**：手动暂停、每屏覆盖、锁屏、电池、节能和远程会话按可用环境验证；多个原因叠加时不提前恢复，界面显示实际原因。
- [ ] **资源与流畅度**：在相同配置下记录改动前后的空闲、搜索、连续拖动、全屏、锁屏恢复场景；不可见界面的无用绘制停止，重复开关面板后内存不持续无界增长，实际操作没有新增明显卡顿。
- [ ] **数据与退出**：保存失败、外部修改冲突、异常组件恢复与正常退出均可处理；笔记和生态瓶数据保留，退出恢复原生图标与任务栏。
- [ ] **构建与交付完整性**：相关现有检查和新增行为检查通过，候选包包含全部必要资源；README、隐私说明和第三方声明与最终实现一致。构建完成、实机验收、安装、推送与发布分别记录状态。

完成标准是上述功能形成连贯的桌面体验，并有对应验收证据。实现、自动检查、实机验收、安装与发布分别记录；本文不授权安装、推送或发布。

## 歌词配色补充要求

依据本次追加的 Dock Lyrics 截图，在既有歌词栏中加入本地专辑封面取色、切歌配色平滑过渡与可选的缓慢背景颜色流动。提供专辑流光、跟随壁纸、透明配色、深海、松林、暖沙、夜紫，配色强度独立于文字颜色与字效。保持现有液态玻璃材质，不新增毛玻璃。

旧设置默认保持原外观；缺封面时回退壁纸。减少动效、暂停与不可见状态停止颜色运动；快速切歌不让旧配色请求覆盖当前曲目。背景配色不单独联网下载封面，不启用原先关闭的歌词或联网开关。
