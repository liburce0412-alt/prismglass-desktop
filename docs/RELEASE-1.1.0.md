# PrismGlass Desktop 1.1.0 正式版

发布日期：2026-11-01。Windows 10/11 x64，下载 [PrismGlass-Setup-1.1.0-x64.exe](https://github.com/liburce0412-alt/prismglass-desktop/releases/download/v1.1.0/PrismGlass-Setup-1.1.0-x64.exe)。

## 桌面视觉与操作

- Dock 连续波峰按实际经过时间平滑跟随，邻近图标放大并让位；修正全部固定项的居中和分隔线位置。
- 仅当前悬停图标显示上方名称胶囊，与 Dock 共用 Sky/Astro 玻璃材质；顶部按钮使用相同胶囊。统一圆角、图标和控件比例，保留边框跟手流光与选中形变。
- 左右栏统一宽度、外边距和选中效果；修复顶部大矩形焦点框、展开灵动岛时的提示遮挡和部分重复边框。
- 可选天气、性能、时钟、日历、电池、常用位置、音乐、专注、工具九种桌面卡片。默认不添加；拖动松手或恢复位置时避让开启的侧栏，隐藏侧栏后可使用该区域。移除保留内容与位置。
- “管理”直达“设置 → 桌面组件”；卡片与两侧栏设置在普通窗口中并排，窄窗口可滚动。网络面板新增 Windows Wi-Fi 选择入口。

## iPad 输入、画面与声音

- 新增直接点选与拖动、Windows 原生双指触摸，保留触控板；停止投屏释放触点与鼠标按键，并处理 Windows 触摸抑制后的指针恢复。
- 中文手动发送支持最多 1024 个 UTF-16 单元，保护组词与未确认草稿；不自动重发。硬件键盘直输为显式选项，通用多行输入仍不支持。
- 默认保持画面比例，可显式拉伸；利用留白分组放置控制，键盘弹出后尽量保留画面。顶部至少预留 24 CSS 像素并遵从系统安全区。
- 短暂连接波动有界重试，保留有效来源与画质选择；恢复时停止输入，主动停止后不自动重开。
- 新增单独授权的电脑系统声音，Safari 必要时点按播放；电脑音量与 iPad 音量分别控制，关闭声音不关闭画面。退出、撤权和超时清理采集进程。
- 电源操作记录最后一次执行结果，区分倒计时、提交和失败；不强制关闭未保存应用。真实关机已由用户确认成功。

## 可选 NPU 工具

设置中的“文字提取”可使用 Intel NPU 识别当前屏幕，通过本机内存管道返回结果；截图与文字不上传、不落盘，点击复制才写入剪贴板。需要单独准备 Python、模型和兼容驱动，普通安装不下载模型。图像超分仅保留实验，未接入实时投屏。见 [NPU 说明](NPU-TOOLS.md)。

## 升级与验证边界

同一安装原位升级，保留用户设置、应用整理、配对及既有权限；新增声音共享默认关闭。桌面卡片默认空列表。旧手工部署目录仍需按现有说明处理，不自动覆盖未归属安装、扩大网络权限或启用 RDP。

本轮完整行为与语法回归通过；此前同一功能候选已通过 188 项隔离 WebView UI、33 项原生工作区、19 项侧栏几何、26 项原生卡片与避让、50 项设置及管理路由检查。真实 iPad 用户确认点按、长按、双指缩放、中文组词删改发送及可听声音。设备结果与电脑侧检查分开记录，详见 [验证概述](VALIDATION.md)。

- 安装包尚未数字签名；未覆盖所有电脑、依赖安装与物理显示器 / DPI 组合。
- 当前虚拟显示驱动拒绝竖屏配置（Win32 31），回退 1440×1080；不承诺所有 iPad 比例均能建立对应虚拟屏。
- Safari 音画同步、耳机切换、“仅 iPad 出声”、硬件键盘组合、跨网络恢复与长期稳定性尚未全面验收。声音与视频仍需单独配置 FFmpeg / MediaMTX；详见 [投屏说明](COMPANION-SCREEN.md)。
- Wi-Fi 入口调用已检查，未执行真实网络切换；Dock 更新频率记录不是屏幕呈现帧率，也不代表用户最终观感验收。
