# PrismGlass Desktop 0.9.2

本版加入软件内检查更新、按需开启的 iPad 独立副屏，以及换网后的视频连接检查与修复。现有桌面材质、歌词和设备配对继续保留。

## 下载与升级

下载 **PrismGlass-Setup-0.9.2-x64.exe**，适用于 Windows 10/11 x64。退出 PrismGlass 后，在原位置运行安装器升级；保留应用整理、个人设置、笔记和配对。使用 Windows 自带 PowerShell 5.1，无需另装 PowerShell 7。升级后在电脑重新「检查并连接」，iPad 刷新页面以载入新版。

安装仍需要 Rainmeter、WebView2 Runtime 和 .NET Framework 4.8，中文向导提供依赖检查与官方安装入口。开机自启及伴随屏共享保持用户原来的设置，不因升级新增权限。

## 伴随屏与投屏

- **投屏**选择主屏或有线物理屏；**独立副屏**在点击「打开副屏」时启用受支持的虚拟屏，停止、断线超时或退出后关闭。未开始使用时，不持续占用扩展显示器。
- 切换屏幕时保留原有物理屏复制/扩展关系，保存和恢复桌面图标位置。拔插或显示器排列变化后，所选屏幕按硬件身份核对，避免抓取错误的屏幕。
- 视频跟随当前伴随屏连接的实际地址，避免换 Wi-Fi 后仍绑定旧 IP。
- 换网后先在电脑点「检查并连接」，iPad 再开始投屏。视频规则需要修复时，电脑列出新旧地址和范围；确认并通过管理员提示后自动更新，iPad 等待并继续连接，无需手工编辑 IP。
- 规则限定 MediaMTX、当前专用网卡、UDP 31890 和这一台已授权 iPad，不放开整个局域网。取消不改规则，失败恢复原范围；真正锁屏仍停止共享。

投屏仍需额外配置 FFmpeg、MediaMTX 和兼容的 NVIDIA NVENC；独立副屏另需受支持的 Virtual Display Driver。不会自动下载驱动或替用户接受新的网络权限。安装路径与配置见 [投屏说明](https://github.com/liburce0412-alt/prismglass-desktop/blob/v0.9.2/docs/COMPANION-SCREEN.md)。

## 检查更新

设置页和托盘提供「检查更新」。主动查询本仓库的最新正式版本，验证发布链接后可在浏览器打开下载页；不后台下载或执行安装器。GitHub 匿名 API 限流时，使用同仓库官方发布页作为后备。

## 验证与边界

0.9.2 完整行为与语法回归通过，正式安装包已在本机原位升级、实际启动和退出；65 份个人设置及配对文件保持一致，83 个现有桌面图标坐标保持一致。开发候选版期间，用户已在真实 iPad 确认恢复投屏画面。视频规则修复使用隔离适配器覆盖迁移、取消和回滚，并通过安装后的程序读取真实规则。

**尚未在真实切换 Wi-Fi 后完整重演管理员确认与 iPad 自动续接流程**，也未覆盖干净电脑安装、所有显卡/设备或长时间投屏。规则测试和当前网络检查不等于全部网络环境验收。详细结果见 [验证概述](https://github.com/liburce0412-alt/prismglass-desktop/blob/v0.9.2/docs/VALIDATION.md)。

安装包尚未数字签名。投屏无音频，捕获整块显示器，无公网中继或软件编码回退。反馈请附版本与复现步骤，勿上传配对记录、证书私钥或私人运行目录：[GitHub Issues](https://github.com/liburce0412-alt/prismglass-desktop/issues)。
