# PrismGlass Desktop 0.9.0-beta.3

这版改善从下载安装到日常设置的完整上手流程，保留原有桌面材质、Dock、歌词、应用分类和个人配置。

## 安装与启动

- 使用 Windows 自带 PowerShell 5.1，不必另外安装 PowerShell 7。安装、桌面启动、退出和卸载均支持；已有有效 PowerShell 路径可继续复用。开发构建与测试仍使用 PowerShell 7。
- 中文安装向导自动检测已有组件。缺少 Rainmeter、WebView2 或 .NET Framework 4.8 时，可点击“一键补齐缺失组件”，确认后从官方源下载并调用安装程序。
- Rainmeter 下载校验固定 SHA-256；Microsoft 安装包必须通过有效数字签名及发布者校验。可取消下载、失败后重试，或手动选择已有程序。需要管理员权限时由 Windows 提示；需要重启时提示保存工作后手动重启，不自动重启。
- 静默安装缺少组件会停止并提示，不自动联网下载。只创建一个 `PrismGlass` 桌面快捷方式；不开机自启、不自动开启伴随屏网络服务。
- 从快捷方式启动失败时显示中文原因和本机错误记录位置，后台调用继续保留退出码，避免双击后只有隐藏的错误。

## 首次设置与天气

- 新安装首次进入“开始使用”，集中提供天气城市、歌词、显示器、应用整理和可选伴随屏入口，并说明如何退出恢复普通桌面。
- 已有配置不会自动弹引导，也不会改变原来的联网、歌词和副屏开关；随时可在设置中重新打开“开始使用”。
- “天气城市”支持输入城市、搜索、选择和自动保存；无需脚本或坐标参数。搜索可取消，超时和无结果会给出提示；失败保留原配置。
- 城市搜索仅在主动提交时发送输入的城市名给 Open-Meteo，不读取设备定位。所选城市更新同一天气采集链，桌面和已授权伴随屏使用一致数据。旧坐标在选择前保留，不再固定显示“南昌”。

## 伴随屏连接

- 全新安装可直接通过管理窗完成首次连接配置，无需寻找不存在的旧 `setup-record.json`。
- 新增“连接步骤”和“导出 iPad 证书”，只导出本安装匹配的公开证书。旧配置仍可导入并沿用原信任。
- 网络配置先列出变更范围，由用户确认并通过管理员提示后应用；共享权限仍默认关闭。iPad 上安装证书及启用信任必须由用户手动完成，之后扫码配对并由电脑批准。

## 验证与限制

本地完整行为及语法回归通过；Windows PowerShell 5.1 安装集成、实际启动及退出恢复通过，本机原地更新保留了 57 个个人状态文件。真实 WebView2 设置页、独立 Rainmeter 天气刷新、城市服务请求与伴随屏管理窗均有针对性检查。详细范围见 [验证概述](VALIDATION.md)。

安装包仍未签名。缺失依赖的实际安装没有在干净 Windows 上完整重演，其他电脑、长期性能和新版 iPad 全流程仍待实际使用反馈；不要求关闭安全软件。下载失败可以重试或使用向导中的官方入口。旧手工部署仍不会自动覆盖迁移。

问题可提交到 [GitHub Issues](https://github.com/liburce0412-alt/prismglass-desktop/issues)，附版本及复现步骤。不要上传完整运行目录、配对记录、证书私钥或个人笔记。
