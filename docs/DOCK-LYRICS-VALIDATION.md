## 复现

使用 PowerShell 7；先通过 `scripts/Build.ps1 -CacheRoot <现有SDK缓存目录>` 准备 SDK。无需开启美化：

```powershell
./scripts/Test.ps1
./scripts/TestDockLua.ps1
./scripts/TestDockGlass.ps1 -RainmeterPath 'D:\Rainmeter.exe'
./scripts/TestGlassLyricsUi.ps1 -CacheRoot 'D:\Cache\PrismGlass'
./scripts/TestInstallConfiguration.ps1 -Bundle '<候选安装包目录>'
```

WebView2 检查输出位于 `artifacts/glass-lyrics-ui/captures`，包含 `glass-before-*` / `glass-after-*`、实际音乐面板以及生产 `index.html` 的 `lyrics-contracting` / `lyrics-capsule-*`。测试窗口位于屏幕外，使用人工背景与演示文字；不是完整私人桌面的录屏。脚本退出后移除临时浏览器配置。

SMTC 检查专门使用 Windows PowerShell 5.1，因为这里需要 .NET Framework WinRT 投影。指定独立临时目录：

```powershell
& "$env:WINDIR\System32\WindowsPowerShell\v1.0\powershell.exe" -NoProfile -File ./tests/TestMediaSession.ps1 -DataRoot '<临时目录>' -Helper '<仓库绝对路径>\src\LiquidDesktop\MediaSession.ps1'
```

它只创建测试媒体元数据，不播放音频；退出时释放测试发布器和读取器。
