添加到主屏幕下次，轻点图标就能打开⌄

先使用电脑显示的固定名称入口打开此页，再添加图标。这样换 Wi-Fi 后，收藏的地址也能保持不变。

  1. 在 iPad 的 Safari 中点“分享”（方框向上的箭头）。
  2. 向下找到“添加到主屏幕”，再点右上角“添加”。
  3. 回到主屏幕，轻点 PrismGlass 图标，再点“扫码配对”，对准电脑的配对二维码。

换 Wi-Fi 后，在电脑端点“检查并连接”。电脑需保持伴随屏开启，iPad 与电脑需连接到可互通的局域网。

主屏幕与 Safari 分别记住配对。先添加图标，再在图标内配对一次，仍由电脑确认；以后直接打开图标即可，正常使用会续期。
