# Third-party components and references

- **Microsoft WebView2 SDK / Runtime**: Microsoft components, governed by the license included in the NuGet package and the Runtime terms. Build downloads the SDK and carries its supplied license/notice files into the local bundle. DLLs and browser user data are not committed here.
- **Rainmeter**: external prerequisite, not bundled or relicensed by this repository. See the [upstream project](https://github.com/rainmeter/rainmeter). The included skin templates and Lua integration are part of this desktop project.
- **Open-Meteo**: weather data/service. See [Open-Meteo](https://open-meteo.com/) for attribution and hosted API terms; this project's MIT license does not grant service access rights.
- **apple-flare-halo-shader** by pancao: visual/shader reference used during the desktop's development. The upstream MIT notice is retained in `licenses/apple-flare-halo-shader-MIT.txt`. See [upstream](https://github.com/pancao/apple-flare-halo-shader).
- **webgl-apple-liquid-glass** by Oliver Nemo (MIT): the shared glass shader adapts the circular bevel/thickness, Snell refraction and Fresnel reflection model from [`src/shaders.js` at e8030bd](https://github.com/Oliverrr2424/webgl-apple-liquid-glass/blob/e8030bd0732bc91652e44b85f84e2ed7aa498679/src/shaders.js). The original license is retained in `licenses/webgl-apple-liquid-glass-MIT.txt`. PrismGlass keeps its own renderer, geometry, interaction and wallpaper sampling; the upstream application is not bundled.
- **LRCLIB / NetEase Cloud Music**: optional online synchronized lyric sources. LRCLIB receives the song title, artist, album and duration; NetEase receives a song ID when it can be matched exactly against the user's local playing list. Service access and lyric rights are not granted by this project's MIT license. No lyric dataset is bundled. See [LRCLIB API](https://lrclib.net/docs). [LyricBar](https://github.com/ysheng920/LyricBar) was an architectural reference for Windows media-session lyrics; its source was not copied.
- **NetEase playback-clock compatibility facts**: the verified `cloudmusic.dll` layout for 3.1.41.205529 was cross-checked against [NetEase_Cloud_Music_Local_API](https://github.com/hanbinhsh/NetEase_Cloud_Music_Local_API), including its offset cache. The bounded read-only C# adapter is independently implemented; no upstream application code is included. [now-playing-service](https://github.com/Widdit/now-playing-service) was investigated for UI Automation compatibility; no source from it is included.
- **Folia / Mineradio lyric design references**: [Folia's GlowWord component](https://github.com/chthollyphile/folia-major/blob/main/src/components/visualizer/GlowWord.tsx) and [Mineradio's desktop lyric visual baseline](https://github.com/XxHuberrr/Mineradio-paused/blob/main/docs/DESKTOP_LYRICS_VISUAL.md) informed the visual direction (white text core, coloured glow, configurable typography/palettes and line hierarchy). The capsule, presets, textures and transitions are independently implemented in PrismGlass's own renderer. No upstream code, fonts or assets are copied or bundled, and no upstream frameworks are added. Typeface options use installed system fonts with fallbacks.
- **SydeDock visual reference**: interaction direction was inspired by a public demonstration. No endorsement, official affiliation or right to redistribute the reference video's assets is claimed.
- Application icons are generated from programs installed by the end user. No third-party game icons, artwork, music covers, branded wallpapers or reference videos are shipped in this repository.

Legacy Rainmeter panels refer to EasyBlur for optional background effects. That plugin is not bundled; the main WebGL components do not require it. PowerPlugin and Win7AudioPlugin references rely on the corresponding Rainmeter installation. The public package should be tested on the target installation before enabling optional legacy panels.
